Local-first · Private · Released v0.2.1

A private AI tutor that runs on your machine.

No subscription and no cloud: structured lessons, quizzes, glossaries, and bilingual podcasts, generated by an AI model on your own computer.

Version 0.2.1 — released November 2026. 1,040 automated tests pass, the code is 86% covered, and every automated check is green (including mutation testing). Your lessons and quiz answers stay on your computer — nothing is sent to the cloud and there is no account to create. Like any personal project, it has not had an outside security audit yet.

Why this exists

Alternatives force a false choice: pay per token for a hosted tutor, or paste prompts into a chat and hope. Neither is a study tool. Both leak your material. Study Studio keeps the model, the lesson, and the quiz on your machine.

What it does

  • Structured lessons (sections, glossary, quiz)
  • Bilingual podcast scripts (English / Arabic)
  • Quiz with local scoring + optional AI evaluation
  • Piper TTS to MP3/WAV export (needs ffmpeg)
  • Multi-provider runtime (LM Studio, Ollama, OpenAI-compatible)
  • On-demand model load (no preloading)
  • Learning Journey (progress, streaks, scores)
  • Library in IndexedDB with legacy migration

Honest boundary

Generation needs a local model runtime. Audio export needs Piper voice files plus ffmpeg. On a clean machine with neither, the app will not produce lessons or audio. The mobile client was removed, and a hosted SaaS is not offered. This is not a production deployment claim: there is no external audit, no certified data isolation, and no signed security review. No revenue has been realised.
